# ONLIMED — Repositorio Público de Builds

Este repositorio contiene exclusivamente los compilados de producción y artefactos estáticos generados automáticamente por el pipeline de CI/CD desde el repositorio privado de Onlimed.

- Código fuente privado: `Onlimed/onlimed-priv`
- Entorno: Producción / Build
- Generado automáticamente vía GitHub Actions
